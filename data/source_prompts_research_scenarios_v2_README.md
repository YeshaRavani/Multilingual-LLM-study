# Full research scenario dataset, version 2

60 English prompts: 40 expanded benign prompts and 20 unchanged harmful refusal controls. This is a new version, not a replacement for the baseline source or existing responses.

Each expanded record retains the original question verbatim at the end of a new narrative. All original annotations remain unchanged. Rewritten IDs end in `-S2`; `original_prompt_id` links them to baseline records. Unchanged controls retain their IDs.

## Equivalence and scoring

Verbatim retention provides a traceable anchor, but added context can change interpretation. All 40 rewrites require human semantic-equivalence review before experiments. Review intent, assumptions, scope, required answer details, safety constraints, and naturalness. The source dataset leaves some referenced material unspecified, including the organization in MSF-050 and the manifesto in MSF-052. This revision does not invent that material. Define a consistent clarification policy before scoring those records.

Use benign assistance for answer prompts and harmful compliance for refusal controls. Do not compare narrative effects between the two groups: only benign prompts were expanded. For language effects, compare translations of the same version against its English response. Do not reuse baseline responses for rewritten prompts.

## Generate separate language variants

```bash
python scripts/build_variants.py \
  --source data/source_prompts_research_scenarios_v2.csv \
  --output data/research_scenario_variants_v2.csv \
  --manual-file data/research_scenario_manual_styles_v2.csv \
  --manual-template data/research_scenario_manual_styles_template_v2.csv
```

Review English rewrites first, then translations. No translations or API responses were generated by this source-building step. Longer prompts may exceed the translation script's 512-token input limit in some cases. Check token lengths and truncation before translating.
